# Sales Method Selection

Choose one primary method and at most one supporting method based on the decision the team must make. The current plugin only needs a small B2B/high-ticket method pack; do not combine frameworks for presentation value.

| User problem | Primary method | First output |
| --- | --- | --- |
| Handoff lacks a customer problem | JTBD / Value Proposition | Buyer, job, problem and value evidence map |
| Opportunity qualification is weak | MEDDICC or SPICED | Missing evidence and qualification decision |
| Discovery is shallow | SPIN or Gap Selling | Discovery questions and customer-action plan |
| Value is not connected to results | Value Selling | Business case and proof plan |
| Proposal is not moving | Mutual Action Plan | Customer-owned steps, dates and exit criteria |
| Price pressure dominates | Value Selling + `dsh-business` pricing review | Value/price risk map and approval needs |
| Existing customer may expand | Value review + expansion triggers | Renewal / expansion signal card |

For every selected method, state the decision, evidence status, unresolved fields, risks, customer action, owner and review date. A completed worksheet is not proof of a qualified opportunity.
